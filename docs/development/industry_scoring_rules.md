# 行业评分固定规则

当前版本：`industry_score_v1`。已发布版本不得静默修改；任何阈值或权重变化必须创建新版本（如 `industry_score_v2`），通过独立 PR 更新文档与测试。

总分100分：当日强度25（同层级等权收益分位15、中位收益分位10）；上涨广度20（上涨比例15、中位收益方向5）；强势上涨15（3%强势股比例达到30%满分）；涨停联动15（涨停比例10，0/1/2/3+只分别0/1/3/5）；成交活跃与量价15；持续性5；数据质量5。所有分项及总分保留两位小数。

同层分位为严格小于当前值的有效样本数除以 `n-1`；一级、二级、三级分别计算。排名依次按总分降序、等权收益降序、行业代码升序。

成交比为当日成交额除以前5/20个有效历史日均值，中位成交比同理，历史不含当日。20日不足使用中性7.5分。量比≥1.20为放量、≤0.80为缩量；收益正/负决定价格方向，其他为平量震荡。放量上涨15、缩量上涨8、放量下跌0、缩量下跌6、震荡7.5。总成交额放量但中位成交额比<1时上限12分。

最近5个有效收益日：累计正且上涨≥3日得5，累计正得4，约等于0得2.5，累计负但上涨≥2日得1.5，否则0；不足3日得中性2.5。

质量：覆盖≥95%且complete得5；≥85%得4；≥70%得2.5；>0得1；无有效数据得0。置信度：complete、覆盖≥95%、有效股≥8为high；覆盖≥80%、有效股≥5为medium；存在有效股为low；否则unavailable。

`first_limit_count` 或 `broken_limit_count` 为NULL时保留在证据中，不转0、不扣分，V1总分不依赖二者。所有评分只读本地 `industry_daily_snapshots`，不读取个股日线或Provider。已知限制是历史快照使用当前行业归属。
