# PR5.11 current 归属消解补充规则

同一股票存在多条 `is_current=True` 的行业归属时：

1. 按 `in_date` 取最大日期。
2. 最大日期只有一条，采用该条。
3. 最大日期有多条且完整行业归属一致，去重后采用，并计入 `duplicate_count`。
4. 最大日期有多条且行业归属不同，跳过该股票并报告冲突。

存在有日期记录时，无日期记录不会优先于有日期记录；如果该股票的全部记录都没有
`in_date`，则保守地比较所有候选：归属一致时去重采用，归属不同时报告冲突。

较早日期的 current 记录属于过期候选，不计入完全重复数量，也不会作为最终快照写入。

## 验证

- 单元测试覆盖最大日期唯一、同日重复、同日冲突、有日期与无日期混合、全部无日期。
- 同步仍只写入冲突消解后的当前快照，冲突股票保持跳过并输出结构化日志。
- 2026-08-01 Tushare 全量只读 dry-run：输入 5924 行，得到 5866 只可写股票，
  冲突 0、跳过 0，状态为 `success`，未写数据库。
